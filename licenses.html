Android app: tracker data

The Android app contains information from the Exodus Privacy tracker database, which is made available here under the Open Database License (ODbL) v1.0.

We changed this data for the app:

  • We split signatures that had more than one package into separate entries.
  • We removed trailing dots from package prefixes.
  • We removed signatures that had no package prefix.
  • We mapped the Exodus categories to our own, smaller set of categories.
  • We added a small number of entries by hand where the Exodus data was out of date.

Our version of this data is also available under the ODbL: download the tracker data (JSON). The ODbL applies to this data table only. It does not apply to the PrivacyBrew app.

Exodus Privacy does not endorse PrivacyBrew, and we are not connected to this project. We thank them for this work.
